## 設計原則

1. 地図は主役、一覧は比較と代替操作を担う。
2. 公的認定に見えるラベルを使わない。
3. 絞り込みは確認済み根拠だけを対象にする。
4. 未確認は欠落させず、琥珀色の中立的な状態として表示する。
5. Access Cardは具体情報、根拠、証拠日時、最終確認日をひとまとまりにする。
6. モバイルでは地図と一覧を明示的に切り替え、詳細は下部シートで表示する。

## デザイントークン

- 背景: `#F7F5EF`
- 文字: `#17324D`
- 確認済み: `#397A62`
- 選択: `#E4775A`
- 未確認: `#B87317`
- 補助面: `#DCECF1`
- UI: 1px border、8–18px radius、選択詳細だけに影
- 書体: Hiragino Sans / Yu Gothic / Noto Sans JP / system sans

## 情報構造

- ヘッダー: ブランド、日英切替、管理導線
- 絞り込み: 検索、具体条件、クリア、モバイル表示切替
- 本体: 一覧 + 地図
- 詳細: 日英Access Card、根拠行、証拠日時、最終確認、外部地図、修正依頼
- 管理: JSON取り込み、公開URL取り込み、処理結果、失敗ログ再送
